# Licenses and distribution

The project source in this repository is MIT licensed; see the root LICENSE.
The Plow OpenClaw variant uses a separate, digest-pinned Plow base image. Its
runtime components and the inherited Agent Index client retain their upstream
licenses and notices; this repository does not replace those terms.

The hackathon Dockerfile does not install CuraEngine or another slicer binary.
The optional root Dockerfile.cura and files under experiments/slicing are
separate investigation assets. Anyone who builds or redistributes a slicer
image must review the relevant package/source licenses and provide notices and
source offers as required by those licenses.

WhatsApp-related source files are experimental and are not built or activated
by the Plow variant. No WhatsApp session or account material is included.
