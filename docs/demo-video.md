# Hackathon demo video

**Status: not recorded.**

The hackathon calls for a public video at least 60 seconds long. Record it from
a real installation of this repository on the Plow base after a tester has
used the standard Plow chat line. Do not create synthetic prompts, fabricated
reporting output, or a simulated install.

## Capture plan (60–90 seconds)

1. Show the Print Farm Operator listing and say that it helps a small 3D
   printing business coordinate production.
2. Show the tester's new Plow installation and the actual Plow chat line.
3. Complete one or two farm onboarding questions and show the agent save the
   answer.
4. Ask for the persisted farm configuration or analyze a public sample STL
   staged in that installation. Show the real result.
5. Describe the boundaries: quotes remain gated, production is operator
   confirmed, and the agent does not control printers.
6. End on the public repository and Agent Index listing.

Before publishing, review the recording for API keys, Plow credentials, private
conversation content, customer information, local data paths, and personal
media. Add the published YouTube video ID to Agent Index metadata through the
official CLI or the listing editor.
